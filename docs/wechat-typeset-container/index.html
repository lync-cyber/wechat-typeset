原则 / PRINCIPLES
  1. 用几何结构、字号对比、颜色层级、留白代替边框与色块装饰。
  2. 每类容器及其变体必须有独立的视觉识别逻辑，绝不共用同一种装饰手法。
  3. 禁用任何形式的侧边色条（border-left/right）。
  4. 禁用彩色顶部色块（header bar）。
  5. 禁用将 box-shadow 作为容器的唯一视觉特征。
  6. 禁用所有容器使用同一种高亮或强调方式。
  7. 禁用用 emoji 替代真实设计元素。
  8. 正文衬线优先，行距 ≥1.8；数字与拉丁名走等宽，与中文形成微妙节奏。
  9. 移动优先：字号 ≥15px，单行字数 ≤22 字。
  10. 留白即设计：宁可多一个空段，不要压缩段间距。
