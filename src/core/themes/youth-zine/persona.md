# 青年潮志（youth-zine）

**一句话定位**：鲜玫粉 + 圆角胶囊 + 高行距，为 Gen-Z 博主量身打造的潮流文体主题。

**视觉签名**：primary 取 #e91e63（玫粉，色相 333°），在 14 个主题中唯一的 pink/magenta 家族；纯白底 #ffffff + 微粉调 bgSoft #fdf6f8，拒绝暖米色调；圆角 lg=14px 显著更圆；行高 1.85 搭配段间距 22px，为短段落留足呼吸。

**核心 voice**：`==高亮==` 被渲染为亮黄（#ffd54f）圆角胶囊标签，是全篇最高频的"打标签"手势；h2 用玫粉色直接担纲，无需额外装饰符。

**适用场景**：小红书种草文、B 站专栏、潮流安利、二次元周边评测、Gen-Z 自媒体。段落简短、标签密集、色彩饱和，这个主题都能接住。

**升级了 5 个 orphan variant**：pill-tag（胶囊标签）/ chat-bubbles（气泡对话）/ triptych（三宫格）/ stamp-quote（印章引用）/ ai-notice（AI 注释卡）。
