# 公文公报

公文公报主题服务于**政务通告、企业公告、监管声明、招股说明书、严肃通报**等正式文体，视觉参照中央人民政府公报、证监会公告与上市公司年度报告。

## 视觉签名

打开一份公文的第一印象：**普鲁士蓝标题 + 铜版纸底色 + 方格框线**。主色 `#1c3a6e`（HSL 219°，饱和度 59%）是政务蓝的权威感；暗金 `#8a6a14` 取自烫金印章记忆，极度克制，只出现在期号印章与分隔点。底色 `#faf8f3` 模拟国务院公报的铜版纸质感。

## 排版纪律

- 字距 0.2px、行高 1.65——公文密度优先，不走杂志式宽松
- h1 居中，h2 自动中文章节序号（一、二、三）
- 正文首行缩进两字——符合国标公文格式
- 所有容器直角或极小圆角，框线主导分层，无鲜艳底色装饰

## 容器选择

公告横幅用 `stamped-banner` 印章式双栏；admonition 走 `top-bottom-rule` 上下框线；note 走 `editorial-stripe` 编注侧条；pull-quote 走 `centered-rule` 居中夹线——四个 orphan variant 全部激活。脚注密集公文首选 `dense-academic`，参考文件走 `academic-refs`。
