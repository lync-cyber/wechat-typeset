# 电商脉动（commerce-pulse）

## 主题定位

专为 B2C 电商、直播带货、双 11 大促、美妆服饰 KOC 及抖音电商内容设计的高密度带货排版主题。核心语言：促销紧迫、价格优势、限时驱动、KOL 背书。

## 视觉签名

**主色朱砂橙红 `#c4310e`**——取自中国朱砂家族，色相 HSL(12°, 87%, 41%)，与 swiss-grid 国际红 `#e30613`（HSL 356°）色相差 16°、亮度差 5%，满足"至少色相差 15° 或亮度差 10%"的隔离要求。白底对比度 5.54:1，符合 WCAG AA。

**金色 accent `#c89759`**——稀缺点缀，用于 VIP 徽章、限量标签、推荐角标，每篇不超过三处。

**炭灰 secondary `#2a2a2a`**——正文粗体、边框压色，让朱红更聚焦。

## 排版策略

- `h1 = 28px / h2 = 22px`，大字号强化标题冲击力，`letterSpacing = 0.3` 紧凑有力
- `recommend` 容器顶部朱红 3px 色条 + 浅暖粉底，是页面最显眼的商品推荐卡
- `footerCTA` 使用 `triptych-actions` 三联格（买 / 收藏 / 分享），承接行动转化
- `announcement` 朱红左条 + 粗体，传达"秒杀 / 限时"极强紧迫感
- `pullQuote` 使用 `giant-mark` 巨号引号，放大 KOL 金句和爆款话术
- `strong` 元素直接染朱红，让价格和卖点自然跳出
