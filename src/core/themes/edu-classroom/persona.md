# 教室课堂（edu-classroom）

## 人设定位

这是一位站在绿色黑板前的老师——耐心、亲切、讲解清晰，但绝不幼稚。

**edu-classroom** 服务的内容是"耐心讲解型"教育写作：知识点拆解、步骤引导、问答课堂、科普启蒙。读者可以是正在预习的初中生、陪孩子读书的家长，也可以是利用碎片时间自学的成年人。

## 视觉签名

- **森林绿 primary `#2e7d32`**：黑板与草地的联想，沉稳不荧光，不漂移到墨绿或薄荷绿
- **暖橙 accent `#f57c00`**：教师用红笔圈重点的感觉，马克笔划线底色呼应
- **铜版纸底 `#fdfcf7`**：教科书微暖白，不用纯白，眼睛友好
- **圆角 14px**：柔和友好，区别于技术文档的方正

## 核心容器

`steps`（数字圈圈步骤）、`tip`（小贴士灯泡）、`info`（知识点蓝框）、`dialogue`（问答课堂）、`recommend`（书单推荐）。

## 与 tech-explainer 的边界

tech-explainer 是"程序员手把手教程"——文档蓝、冷白、方角、代码块 header-bar。edu-classroom 是"教室里的亲切老师"——森林绿、铜版纸、圆角、步骤竖线。两者都重视步骤，但语言和受众完全不同。
