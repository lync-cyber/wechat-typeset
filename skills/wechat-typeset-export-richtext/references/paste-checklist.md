# 粘贴 checklist（独家 reference）

> render 完成后，把 HTML 复制粘贴到公众号编辑器时的人工 checklist。
> 本工具触达不到公众号后台——以下步骤必须在公众号编辑器里手动完成。

## 粘贴前（在浏览器 / 本地）

- [ ] 已跑 `lint-contract.ts`，确认 markdown 通过契约校验
- [ ] 已跑 `render-html.ts`，得到 `output.html`
- [ ] 浏览器打开 `output.html`，肉眼检查：
  - [ ] 容器（`:::`）有视觉骨架（admonition 左边线、quote-card 装饰等）
  - [ ] SVG 装饰（h2Prefix / divider）渲染完整
  - [ ] 5 个行内扩展（`==` / `[.着重.]` / `[~波浪~]` / `~~` / `++`）效果正确
  - [ ] 代码块（如果有）语法高亮正常
  - [ ] 图片（`![](...)`）链接有效（不是 broken image）

## 粘贴动作

1. **浏览器开 `output.html`**
2. **Ctrl+A 全选**（macOS：Cmd+A）
3. **Ctrl+C 复制**（macOS：Cmd+C）
4. **打开公众号编辑器**：https://mp.weixin.qq.com → 写文章
5. **Ctrl+V 粘贴**（macOS：Cmd+V）到正文区
6. **等 2-3 秒**——公众号编辑器需要时间解析富文本

**注意**：

- 如果粘贴后只剩纯文本（样式全丢）→ 剪贴板里只有 `text/plain` MIME；重做：浏览器内右键 → "复制"而非 Ctrl+C，或者用 `scripts/copy-richtext.ts` 写入富文本剪贴板
- 如果粘贴后样式部分丢失 → 是公众号编辑器的解析问题；尝试切换粘贴方式（"粘贴并匹配样式"）

## 粘贴后（在公众号编辑器）

### 必做

- [ ] **标题**：在顶部输入文章标题（粘贴不会自动填充）
- [ ] **作者**：默认是公众号主体名，可在右侧栏修改
- [ ] **摘要**：右侧栏"摘要"区，≤120 字（建议从 `::: intro` 或 `::: abstract` 复制核心句）
- [ ] **封面图**：右侧栏"封面图"上传
  - 如果 markdown 里有 `::: cover` 容器，公众号会把第一张图识别为封面候选
  - 不识别时手动上传
- [ ] **原创声明**：底部"声明原创"勾选（如果是原创）

### 可选

- [ ] **mpvoice / mpvideo 占位卡**（如有）→ 删除占位 → "插入音频/视频"补真节点
- [ ] **公众号视频**：`::: mpvideo qqvid=xxx` 已渲染为腾讯视频 iframe，无需替换；`::: mpvideo vid=wxv_xxx` 是公众号视频占位，需替换
- [ ] **小程序卡片**：公众号正文里小程序需要"@小程序"原生插入，粘贴拿不到
- [ ] **页内锚点**（`#anchor` 链接）：公众号支持 hash 锚点，但 anchor 目标必须是 H2 标题，且需要在公众号编辑器里手动加锚点 id（粘贴不会保留）

### 检查外链

公众号正文里 `<a href>` 行为受平台限制：

- ✅ **白名单 URL**（点击可跳）：
  - `https://mp.weixin.qq.com/s/*`（同域历史文章）
  - `weixin://dl/*`（小程序协议）
  - `tel:*` / `mailto:*`（系统协议）
  - `#anchor`（页内锚点）
- ❌ **普通 https 链接**：渲染为灰色不可点文字（读者点会弹"已停止访问该网页"）

**`::: footer-cta` 的 href**：白名单 URL 在公众号正文里可点；非白名单原样保留（在预览 / 导出长图里仍可点，公众号正文不行）。

### 推荐的转化路径

1. **阅读原文**：公众号文章有"阅读原文"位（在后台发文时手填），最稳的站外跳转
2. **二维码**：`::: qrcode` 容器 + `::: footer-cta` 组合——按钮做引导，二维码做实际跳转
3. **同域文章链**：footer-cta `href=https://mp.weixin.qq.com/s/...`，公众号内互导

## 手机预览

- 点击公众号编辑器右上角"预览"图标
- 扫码或同账号小程序里看
- **必做检查**：
  - SVG 图标 / 二维码完整显示
  - 字号在 375px 下不糊（baseSize < 14 时会糊；硬约束已挡）
  - 5 态 admonition 容器（如果用了）颜色清晰，不要全部都灰一色
  - 表格不溢出屏幕（公众号会自动 horizontal scroll，但密集表格读起来很费劲）

## 发布前最后一道关

发布按钮按下前再看一眼：

- [ ] 标题（中文+英文标题分隔符是中文括号 `（）` 还是英文 `()`，前后统一）
- [ ] 封面（与文章气质匹配，不要随便用一张图凑）
- [ ] 摘要（不超 120 字，预览图下方显示）
- [ ] 原创声明（无误）
- [ ] 留言开关（粉丝交互入口）
- [ ] 赞赏 / 在看 / 分享设置

发布后**不可改文章主体**（公众号只允许改一次错别字，且改 5 处以内）——粘贴前的 checklist 是最后一道保险。

## 出锅排查

| 症状 | 推断 | 修法 |
| --- | --- | --- |
| 粘贴后样式全丢 | 剪贴板只 text/plain | 用 `copy-richtext.ts` 或浏览器右键"复制" |
| 部分容器样式丢失 | 公众号编辑器解析 partial fail | 尝试"粘贴并匹配样式" / 或拆段粘贴 |
| SVG 装饰发灰 | `#fff` 没换 `#fefefe`（理论不应发生，WxPatch 已处理） | 报 issue 到 wechat-typeset |
| 代码块字号过小 | 主题 `code` 字号 < 14（不应发生，校验已挡） | 报 issue |
| 图片不显示 | markdown 图片 URL 域名公众号防盗链 | 改用公众号上传的图（先上传图床到公众号后台） |
| 表格错位 | 公众号 horizontal scroll 默认开 | 简化表格列数 / 改用 highlight + 短列表 |
